# 🏮 신청함 + 인명부 자동화 설정 (구글 시트)

무림강호 때와 같은 방식(구글 시트 + Apps Script)인데, **한 가지가 달라졌어요.**

> 예전: 시트에 쌓인 신청을 보고 → `characters.json`을 손으로 고쳐 → GitHub에 다시 올림
> **지금: 시트에서 `상태` 칸을 "활동중"으로 바꾸면 끝.** 인명부가 시트를 직접 읽습니다.

GitHub은 처음 한 번만 건드리고, 그 뒤로는 **시트만 관리**하시면 됩니다.

---

## 1. 구글 시트 만들기

1. https://sheets.google.com 에서 **새 스프레드시트** 생성
2. 이름을 `달빛여관 신청함`으로 변경
3. **아무것도 입력하지 마세요.** 제목행은 첫 신청이 들어올 때 자동으로 생깁니다

> 🔄 **이미 연결해두셨고 관리 페이지만 추가하는 경우** — 2번(코드 붙여넣기)만 다시 하고, **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 누르면 끝입니다. URL은 그대로예요. (「새 배포」를 만들면 URL이 바뀌니 누르지 마세요.)

## 2. Apps Script 넣기

1. 시트 메뉴 **확장 프로그램 → Apps Script**
2. 편집기에 있는 코드를 전부 지우고, 같은 폴더의 **`apps-script.js`** 파일 내용을 전체 복사해서 붙여넣기
3. 저장(💾)

## 3. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(⚙️) → **웹 앱**
3. 설정
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 중요
4. **배포** → 권한 허용 (경고가 떠도 **고급 → 이동**으로 진행)
5. 생성된 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)

> ⚠️ 나중에 코드를 고치면 **배포 → 배포 관리 → 새 버전**으로 재배포해야 반영됩니다.

## 4. 사이트에 연결 (GitHub, 한 번만)

1. `characters.html`을 메모장으로 열기
2. 이 줄을 찾아서
   ```
   const APPLY_URL = '';
   ```
3. 따옴표 안에 복사한 URL 붙여넣기
   ```
   const APPLY_URL = 'https://script.google.com/macros/s/…/exec';
   ```
4. 저장 → GitHub에 업로드

---

## 4-1. 캐릭터 이미지

신청할 때 올린 이미지는 내 구글 드라이브의 **`달빛여관_이미지`** 폴더에 자동 저장되고(없으면 자동 생성), 시트의 `이미지` 칸에 보기용 주소가 들어갑니다.
그래서 코드를 이 버전으로 올리고 **새 버전**으로 배포할 때 **드라이브 권한 허용 창이 한 번 더** 뜹니다. 고급 → 이동 → 허용으로 진행하세요.

## 5. 운영 — 관리 페이지 또는 시트

사이트 왼쪽 맨 아래 **🗝** 를 누르면 관리 페이지(`admin.html`)가 열립니다.
비밀번호는 `apps-script.js` 맨 위 `ADMIN_KEY`에 적힌 값입니다(기본 `2328`, 바꾸려면 코드에서 고치고 **새 버전**으로 재배포).

| 관리 페이지에서 | 하는 일 |
|---|---|
| ✓ 승인 | 상태를 `활동중`으로 — 인명부에 바로 보임 |
| 반려 · 휴면 · 소멸 | 상태 변경 (소멸은 「설의 도서관」에 책으로 남음) |
| ✎ 수정 | 오타 등 내용 고치기 → 저장 |
| 삭제 | 시트에서 행을 완전히 지움 (소멸한 캐릭터는 삭제 말고 소멸 권장) |

같은 일을 구글 시트에서 직접 해도 됩니다. 아래는 시트로 할 때의 설명입니다.

### 시트로 관리할 때

신청이 들어오면 시트에 이렇게 쌓입니다:

| 날짜 | 상태 | 이름 | 오너 | … |
|---|---|---|---|---|
| 9. 17. 오후 3:12 | **심사중** | 누렁 | 달빛토끼 | … |

### 승인
> `상태` 칸을 **`활동중`**으로 바꾸세요. **그게 끝입니다.**
> 인명부 페이지를 새로고침하면 바로 보입니다.

### 상태 종류

| 상태 | 인명부에서 |
|---|---|
| **심사중** | 안 보임 (기본값) |
| **활동중** | 보임 |
| **휴면** | 흐리게 보임 + 「휴면」 표시 |
| **소멸** | 아래쪽 **「설(說)의 도서관」** 에 책으로 남음 |
| *(그 외 아무 글자)* | 안 보임 — 반려하고 싶으면 `반려`라고 적으세요 |

### 수정
신청 내용에 오타가 있으면 **시트 칸을 직접 고치면** 됩니다. 사이트에 바로 반영돼요.

### 삭제
행을 지우거나, 상태를 `반려`로 바꾸면 사라집니다. **소멸한 캐릭터는 지우지 말고 `소멸`로** — 세계관상 책으로 남는 게 맞으니까요.

## 💡 편하게 쓰는 팁

**상태 칸을 드롭다운으로** — 오타 방지
1. `상태` 열(B열) 전체 선택
2. 메뉴 **데이터 → 데이터 확인**
3. 기준: **드롭다운** → 항목에 `심사중, 활동중, 휴면, 소멸, 반려` 입력 → 완료

**새 신청 알림 받기**
1. 시트 메뉴 **도구 → 알림 규칙**
2. "변경사항이 있을 때 · 이메일 즉시" 선택

## ❓ 문제가 생기면

| 증상 | 원인 |
|---|---|
| 인명부가 "시트를 불러오지 못했어요" | 배포 시 액세스 권한이 **모든 사용자**가 아님. 또는 코드 수정 후 재배포 안 함 |
| 신청 눌러도 시트에 안 쌓임 | `APPLY_URL`에 URL을 안 넣었거나, URL 끝이 `/exec`가 아님 |
| 승인했는데 안 보임 | `상태`에 `활동중` 앞뒤로 공백이 있거나 오타. 드롭다운을 쓰세요 |
| 제목행이 이상함 | 시트에 뭔가 미리 입력했을 때. 새 시트로 다시 하세요 |
