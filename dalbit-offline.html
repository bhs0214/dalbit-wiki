✦ 세계 개요
🌍세계관 기본
▶
"달빛이 설(說)을 비출 때 영물들은 피어난다."
배경가이아 대륙. 죽은 동식물이 영물이 되어 사는 사후세계. 약 5천 년 전 세상이 이야기로 열림.
대륙판테라(동·북) / 다오렌(남) / 레퀸(서)
영물선한 이야기로 태어난 존재. 양기 보유. 인간 외형+고유 신체(꼬리·날개·뿔 등).
요괴악한 이야기로 태어난 존재. 음기 보유. 영물 섭취해야 생존. 미섭취 시 소멸.
탄생구전·설화로 태어나거나, 영물세계에서 태어난 2세 존재.
양기=영물 음기=요괴 혼혈 가능
⚡영력·술식·의식
▶
영력이야기에서 나오는 에너지. 마나 역할. 양기(영물)·음기(요괴)로 구분.
술식즉시 발동 마법. "가랏 파이어볼" 수준.
의식채널링 마법. 집중 시간 길수록 위력↑. 마법진 기반.
술식 4종류
회복청룡·잉어 가문 원조. 식물계 파생.
신체강화백호·범 가문 원조. 육상생물 파생.
양기(공격)주작·참새 가문 원조. 오행(화수목금토) 원소 마법. 비행생물 파생.
음기(방어)현무·거북 가문 원조. 수생생물 파생.
⚠ 양기+음기 동시 사용 = 즉시 소멸. 4신수도 예외 없음.
위력식영물: (양기)-(음기) / 요괴: (음기)-(양기)
속성 구분따뜻·밝음=양기 / 차갑·어둠=음기 (얼음·그림자도 음기 계열)

⚔️법기
▶
개념소중했던 물건·잊고 싶지 않은 이야기 관련 물건을 실체화. 인챈트 개념.
개수1령당 보통 1개, 최대 2~3개.
조건자신과 무관한 물건은 사용 불가.
전투형검·창·활·채찍·지팡이·총기·부적·반지·안경·신체 자체 등.
비전투형나침반 반지·시야강화 안경·자동청소 빗자루 등.
전투·비전투 용도 구분 없이 자유롭게 사용 가능.

2500살. 165cm. 분홍빛 백옥 피부·금발 웨이브·분홍 돼지 귀·자주색 눈동자. 항상 와인잔 들고 있음. 돈·명예·예술·빈곤한 예술가 후원 좋아함. 돼지고기 극혐·뚱뚱하다는 말 금기. 법기: 가문 문장 금화. 술식: 거대화·재물복.
법기: 가문 문장 금화술식: 거대화·재물복돼지고기 언급 금기
🦂
회사 (灰砂)
전갈 영물 · 도개사 암시장 운영자
모래색 두건으로 얼굴 가림. 성별 불명. 극도로 사무적. 모든 거래 내역 암기. 약속 어기면 가차없음. 홍연과 묘한 연결 고리.
"필요한 것만 말하시오"
🦋
나비진 (羅緋塵)
나비 영물 · 정보상
수다스럽고 쾌활. 금방 친해지나 정보 팔 땐 감정 없음. 정보엔 정보로 값 치름. 첫 만남엔 "가장 재미있는 이야기" 요구.
"더 재미있는 거 알려드릴까요?"

철흑 (鐵黑)
두더지 영물 · 금지 법기 거래상
말수 적음. 물건 애착 강해 팔기 싫으면 가격 터무니없이 높게 부름. 왼팔 없음(잘못된 법기에 먹힘). 반품 불가. 부작용 본인 책임.
"한 번 보고 판단해요"

✦ 기본 개념
⚡영력 (靈力)
▶
정의이야기에서 나오는 에너지. 영물세계를 지탱하는 근원적 힘. 판타지의 마나(Mana)에 해당.
종류양기(陽氣) — 영물이 보유. 선한 이야기에서 비롯.
음기(陰氣) — 요괴가 보유. 악한 이야기에서 비롯.
위력식영물: (양기)-(음기) = 술식 위력
요괴: (음기)-(양기) = 술식 위력
⚠ 양기+음기 동시 사용 시 즉시 소멸. 4신수도 예외 없음.
📖이야기 (說)
▶
정의영물세계의 근본 원리. 존재의 업적과 가치를 담은 서사.
영향선한 이야기 → 영물로 태어남
악한 이야기 → 요괴로 태어남
중요성이야기가 있어야 영물세계에 올 수 있음. 이야기가 없으면 이름도 남지 않음.
"이야기가 있는 자에게는 이름이 남는다. 그것이 선이든, 악이든."
🌟영물 (靈物)
▶
정의선한 이야기로 태어난 존재. 양기 보유.
탄생① 구전·설화로 전해진 이야기로 태어남
② 영물세계에서 태어난 2세
외형기본적으로 인간형. 꼬리·날개·귀 등 고유 신체 유지 가능.
특이사항음기가 극단적으로 치우치면 요괴화 가능 (전설).
🌑요괴 (妖怪)
▶
정의악한 이야기로 태어난 존재. 음기 보유.
생존영물을 섭취해야 생존 가능. 장기 미섭취 시 소멸.
섭취 효과영물 섭취 시 이야기·양기 흡수 → 강해짐.
신체술식 없이도 영물보다 신체 능력이 월등히 강함.
특이사항착한 요괴 가능하나 서사적 뒷받침 필수. 영물과 혼혈 가능.
✦ 술식·의식·법기
✨술식 (術式)
▶
정의영력을 이용한 즉시 발동 마법. "가랏 파이어볼" 수준.
특징빠르고 간단. 일반 마법 형태.
종류회복 / 신체강화 / 양기(공격) / 음기(방어)
기원5000년 전 사신수(청룡·백호·주작·현무)가 최초 제작.
🔮의식 (儀式)
▶
정의마법진 기반 채널링 마법. 집중 시간이 길수록 강해짐.
특징술식보다 강력. 시전 시간 필요. 영력을 지속 집중.
위력집중 시간에 비례. 대국급 도달 가능.
⚔️법기 (法器)
▶
정의소중했던 물건·잊고 싶지 않은 이야기 관련 물건을 실체화한 무기. 인챈트 개념.
조건자신과 관련된 물건만 사용 가능. 무관한 물건은 단순 물체.
개수1령당 보통 1개, 최대 2~3개.
종류전투형: 검·창·활·채찍·지팡이 등
비전투형: 나침반·시야강화 안경 등

✦ 위력 등급
💥위력 등급
▶
대령1대1 특화. 영력 소모 적음. 집중하면 대국급 도달 가능.
대역다수·범위 공격. 결계·방어·버프 포함. 영력 소모 큼.
대국요새 일격 파괴. 집중 시간 필요. 사용 후 전투 종결.
✦ 술식 4종류
💚회복 술식
▶
원조청룡(잉어 가문)
파생식물계 가문으로 파생.
설명상처 치유, 영력 회복, 상태 이상 제거 등.
💪신체강화 술식
▶
원조백호(범 가문)
파생육상생물 계통 가문으로 파생.
설명근력·속도·내구력 강화. 신체 능력 전반 상승.
🔥양기 술식 (공격)
▶
원조주작(참새 가문)
파생비행생물 계통 가문으로 파생.
설명오행(화·수·목·금·토) 기반 원소 공격 마법. 따뜻·밝은 것=양기 계열.
특징오행끼리 섞어 새 술식 창조 가능.
🛡️음기 술식 (방어)
▶
원조현무(거북 가문)
파생수생생물 계통 가문으로 파생.
설명주변 음기를 보호막처럼 두르는 방어 마법. 차갑·어두운 것=음기 계열.
주의영물의 음기량은 요괴보다 훨씬 적어 공격 용도로는 무리.

용례올리비아의 재물복 술식처럼 게임 밸런스에 큰 영향을 주는 능력.
✦ 역극방 기본 규칙
RULE 01
지문과 대사 구분
행동·묘사는 괄호 없이 평서문으로 작성합니다.
대사는 " " 또는 『 』 로 감쌉니다.
Ex) 그가 천천히 문을 밀었다. "여기가 달빛여관인가요?"
RULE 02
탈역 표시
역할극에서 벗어나 본인으로 대화할 때는 앞에 표시합니다.
Ex) (탈역) 잠깐 화장실 다녀올게요!
또는 // 표시를 앞에 붙입니다.
RULE 03
달빛여관 내 규칙
• 여관 안에서는 영물·요괴 모두 능력 사용 불가 (싱귤러 포인트)
• 싸움 금지. 주인 하루의 말은 여관 내 법.
• 요괴도 여관 안에서는 안전 보장.
• VIP룸은 하루의 초대장 필요.
RULE 04
전투 규칙
• 대령급: 1대1 집중 피해. 영력 소모 적음.
• 대역급: 범위·다수 공격. 소모 큼, 남발 불가.
• 대국급: 일격 전투 종결. 신중하게 사용.
• 요괴는 신체 능력 우위. 술식 없이도 영물을 압도.
• 양기+음기 동시 사용은 사용자 즉시 소멸.
RULE 05
캐릭터 생성 기준
• 종으로 가문 설정. 능력으로 가문 설정 X.
• 가문 특기가 반드시 개인 특기는 아님 (예외 가능).
• 법기는 캐릭터와 연관된 소중한 물건이어야 함.
• 요괴 캐릭터는 술식 없어도 됨.
• 착한 요괴는 서사적 뒷받침 필수.
RULE 06
만해지 요괴법
1조: 만해지 내부에서의 사냥 금지. 내부는 휴전지대.
2조: 힘이 곧 발언권. 우두머리는 약자 보호 의무.
3조: 거래·약속은 절대적. 위반 시 전체가 적.
4조: 정체를 묻지 않음. 중앙 첩자 발각 시 추방.
5조: 묵현의 선을 넘으면 봉인 감옥. 예외 없음.
✦ 자주 묻는 질문
❓혼혈 캐릭터는?
▶
양기가 강하면 영물, 음기가 강하면 요괴. 정확히 반반은 불가능.
❓영물이 요괴를 먹을 수 있나요?
▶
가능하지만 혐오 식품 취급. 과복용 비권장. 반대로 요괴가 영물을 먹으면 이야기·양기 흡수해 강해짐.
❓착한 요괴가 가능한가요?
▶
가능은 하나 음기로 인해 대부분 악함. 충분한 서사적 뒷받침이 있어야 사용 가능 판정.
❓용 가문 vs 잉어 가문 차이는?
▶
용 가문=선천적 재능(서양 드래곤 포함). 잉어(청룡) 가문=후천적 노력(동양 청룡만). 등용문 설화에서 유래. 완전히 다른 가문.
❓가문 특기를 꼭 따라야 하나요?
▶
아니요. 종으로 가문 설정하고 개인 특기는 자유. 예외는 항상 존재. 의사 가문에서 화가 재능이 나올 수 있음.
